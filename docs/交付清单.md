## 复跑命令（验收门禁登记 · G-56）

```bash
node tools/selftest.cjs --seeds 200 --demo --json tools/selftest-report.json
node tools/browser-smoke.cjs
node tools/guide-smoke.cjs
node tools/difficulty-smoke.cjs
node tools/make-demo.cjs
```

> 项目为纯静态、无 `package.json`、无 `npm test`；验收门禁以本节命令为准，不虚报接入 npm test。
> `browser-smoke.cjs` / `make-demo.cjs` 使用 `?guide=0` 抑制首次引导，保证既有截图与录屏不被引导层污染。
> `docs/引导-制作人裁决单-v1.md` 为引导实现与验收的冲突终裁；`docs/引导-设计案-v1.md` 为步骤与参数唯一来源。
>
> **引导验收当前结果**：`guide-smoke PASS`，60/60 用例通过，阻断 0；19 帧逐帧 AI 视觉复核全 pass（`visualReviewPass: true`）；
> 负向计数 12 项全 0（引导期间 0 次问话/听风/点灯派发、0 弹窗、0 残留层、0 非本地请求、0 页面报错）；标记写入 完成 1 / 跳过 1 / 重看 0。
> **真人玩家试玩未发生**，故 `humanPlaythroughPass: false`、`humanPending: true` —— 不以 AI 视觉复核冒充真人试玩。
>
> **难度分级验收结果（实测，`QA_DIFFICULTY_RUN=1 node tools/difficulty-smoke.cjs`）**：`PASS`，**44/44** 用例通过、`exit 0`。
> 前置门禁 `specStatus=OK` / `implStatus=WIRED` / 判定工具自验 `23/23` + `10/10`（另 12/12 矩阵、12/12 边界）/ `gate.verified=true`。
> 负向计数**实测**全 0：`seedPollutionCount` `seedRegenCount` `runtimeTierInSeedCount` `noviceLampLeakCount` `inGameTierChangeCount` `illegalTierAcceptCount` `legacySaveRewriteCount` `residualTierStateCount` `nonFileRequestCount` `pageerrorCount` `regressionFailCount`；
> 非法 `?difficulty=` 8 类各提示**恰好 1 次**（`illegalTierToastViolationCount=0`）；引导域 9 项负向计数读 `guide-smoke` 实测值为 0（`guideCounters.pass=true`）。
> 三套既有门禁回归：`selftest 6/6`、`browser-smoke errors=[]`、`guide-smoke 60/60`。
> **探针先自验**：toast 通道 4 个已知答案样本（1 命中 + 3 不命中）4/4、剪贴板通道 3 个样本（1 命中 + 2 不命中）3/3，未自验通过前对应断言一律标 `UNCOVERED`。
> **8 帧逐帧 AI 视觉复核全 pass**（`visualReviewPass=true`，签名见 `docs/screenshots/difficulty-visual-review.json`）。
> **默认档不变性独立复核**：`git worktree` 取 `v1.1.0` 与当前版并排跑 `?seed=X&night=N`（不带 `?difficulty`），3 seed × 3 夜共 **9/9 组 `getState()` 逐字节相同**，老链接/老存档行为未变。
> **未测量的断言不冒充通过**：`hookOnlyCaseCount`（仅靠钩子断言的用例数）需逐条用例声明观测通道才能统计，本轮未测量 → 列入 `coverageGaps`，既不写 0 也不计入通过。
> **真人玩家试玩未发生**：`humanPending: true` / `humanPlaythroughPass: false`，不得用 AI 视觉复核顶替。自动化全绿 ≠ 能玩。

## 六、冲奖策略说明（为什么这样设计）

官网「AI 游戏作品」评分表（已核对）：**可玩性 30 / AI 运用 25 / 完成度 20 / 创意呈现 15 / 手记 10**；
金奖描述为「最好玩、最完整、AI 用得最好的作品」。

**已锁定决策（2026-11-11）**：冲金奖 · **B 方案（端侧小模型 + 云端兜底）** · 已报名、DGX 算力待审批。
核心取舍：**保住"稳"的 50 分（可玩性 30 + 完成度 20），AI 运用 25 用可解释端侧引擎拿满；Docker/付费 GPU 明确不采用，规避持续计费。**

- **可玩性（30）优先于炫技**：3 分钟一局、五种结局、四档难度（新手/初级/中级/高级）+ 三夜递增叠加、语气策略；纯前端无冷启动，手感不受云端影响。
- **完成度（20）不冒险**：免费 CPU 静态托管、零依赖、零密钥、断网可玩；200 组种子自检 + 104 项自动化验收（引导 60 + 难度 44）全通过作为证据；**不选阿里云付费 GPU，公开链接不产生持续计费**。
- **AI 运用（25）拿满**：L0 可解释决策引擎（五维状态 × 效用 × 规则掩码，逐条可验证）+ AI 导演 + 影子掌柜全部参与运行时；L2 云端兜底（`js/llm.js` 已实现，默认关、1.5s 超时静默回退）与 DGX 离线演示（待批）作为**可选增强**，如实披露、不虚报。
- **创意呈现（15）**：「不接黑箱大模型也是 AI 游戏」的反差叙事 + 9:16 竖版社媒宣传片。
- **手记（10）写满**：真实数据、三个真实缺陷前后对比、L0–L3 取舍与"未启用项"如实声明。
- **顺带覆盖特别奖**：最佳 AI NPC、最佳 AI 原生玩法、最佳 Agent 工程实践、最佳创作实践四条线均有可核验材料。
