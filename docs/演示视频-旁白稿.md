# 演示视频旁白稿（配音用 · 对齐 16s 时间轴）

> 成片：`docs/演示视频.mp4`（16 秒真实浏览器录屏，无音轨）
> 分镜依据：`docs/演示分镜脚本.md`
> 合成方式：中文 TTS 生成旁白 WAV → ffmpeg 混流进视频（视频不足处用末帧延展）

## 配音总则

- 语言：中文（普通话）。音色：沉稳男声或干净女声，语速中等偏快。
- 总时长目标 16s；若生成语音偏长，用 `atempo` 轻微加速或末帧延展对齐，不裁剪画面。
- 不抢画面信息：旁白只做「点题 + 强调 AI 可解释性」，不逐字念 UI 文字。
- 结尾必须落到三个卖点：**端侧 AI 决策 / 全程可解释 / 纯静态离线可玩**。

## 合成命令（生成配音版后执行）

```bash
# 1) 生成旁白音频（Windows System.Speech 离线 TTS 或 edge-tts）
#    产出 docs/演示视频-旁白.wav
# 2) 混流：视频无音轨，直接把旁白叠上去；视频短则末帧延展到音频长度
ffmpeg -i docs/演示视频.mp4 -i docs/演示视频-旁白.wav \
  -filter_complex "[0:v]tpad=stop_mode=clone:stop_duration=4[v]" \
  -map "[v]" -map 1:a -c:v libx264 -c:a aac -shortest \
  docs/演示视频-配音版.mp4
```
