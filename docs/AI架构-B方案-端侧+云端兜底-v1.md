# AI 架构 · B 方案（端侧小模型 + 云端兜底）v1

> 决策：**B 方案**；**冲金奖**；评分口径「可玩性 30 / AI 运用 25 / 完成度 20 / 创意呈现 15 / 手记 10」。
> 目标：**避免收费风险**，同时不牺牲评分——保住 50 分"稳"的维度（可玩性 30 + 完成度 20），把 AI 运用 25 用"可解释端侧引擎 + 可选云端兜底"拿满。
> 日期：2026-11-11

---

## 0. 一句话
**核心决策全在端侧、零依赖、可复现；云端只是可选润色，默认关闭、超时静默回退；DGX 若获批仅用于离线演示，不挂公开付费资源。**

---

## 1. 分层架构

| 层 | 名称 | 是否必选 | 运行位置 | 成本 | 作用 |
| --- | --- | --- | --- | --- | --- |
| **L0** | 端侧轻量决策模型 | ✅ 必选 | 浏览器本地 | 0 | 五维状态 × 人格权重 → 效用打分 → softmax 采样 → 规则掩码校验 → 状态回写。**可解释、可复现、断网可玩** |
| **L1** | 端侧措辞生成 | ✅ 必选 | 浏览器本地 | 0 | 人格词典 + 状态/记忆模板组合，产出 NPC 台词（现有能力） |
| **L2** | 云端兜底（润色） | ⭕ 可选，默认关 | 自建/免费额度端点 | ≈0 | 仅对 L1 产出的**表层措辞**做润色；**不改决策**；超时 1.5s 失败静默回退 L1 |
| **L3** | DGX 本地大模型 | ⭕ 若获批 | DGX Spark 本地 | 0（竞赛算力） | 仅做**离线演示 / 录屏 / 评审现场**，不挂公开链接 |
| — | 公开托管 | ✅ | 魔搭创空间 **免费 CPU** | 0 | 静态托管，不选付费 GPU，不产生持续计费 |

> 关键边界：**L0 决策永不上云**。云端只碰"怎么说"，不碰"说什么/怎么判"。这样可解释性与可复现性不被破坏，也避免"接了大模型反而像黑箱"的评审陷阱。

---

## 2. 为什么不是"纯端侧神经大模型"
- 浏览器内跑神经 LLM（WebLLM 等）需下载数百 MB 权重 → **首屏阻塞、冷启动慢**，直接伤"可玩性 30 / 完成度 20"。
- 因此 L0 用**轻量决策模型**（规则+效用+采样，非神经网络），L1 用模板生成；真正的大模型只在 L3 离线演示出现。
- 若未来要加"端侧神经小模型"，必须**渐进加载、默认关、不阻塞首屏**，作为 L1 的可选增强。

---

## 3. 云端兜底契约（L2）

- **开关**：在页面注入 `window.SANDENG_LLM = { endpoint, key?, timeout? }` 即启用；**不注入即关闭（默认纯端侧）**。实现见 `js/llm.js`，挂钩于 `js/main.js` 的 `afterDispatch` 单点，**不触碰 `game.js` 状态机**。
- **实测**：关闭态 `enabled()=false`、`polish()` 原样返回原文；启用态可正确取回 `{text}`；端点不响应时约 1.5s 静默回退原文。
- **请求**：`POST {endpoint}`，body：
  ```json
  { "persona": "...", "state": {...}, "action": "...", "baseText": "..." }
  ```
- **响应**：`{ "text": "润色后台词" }`
- **约束**：超时 **1.5s**；任何错误/超时/空响应 → **静默回退 `baseText`**；失败计数只记本地，不弹窗、不阻塞。
- **安全**：密钥只在玩家自填或服务端代理，**绝不写进前端仓库**；公开链接默认不带密钥、默认关。
- **可复现**：L2 开启与否不影响 `getState()`；自检与 44 项验收**在 L2 关闭下跑**，保证与端侧一致。

## 4. 免费托管与计费规避

| 风险 | 规避做法 |
| --- | --- |
| 公开创空间挂付费 GPU → 有访问就持续计费 | **只选免费 CPU（2vCPU/16GB）**，不选阿里云 PAI-EAS 付费升级资源 |
| 绑阿里云 + 实名被误解为收费 | 实名与绑定**本身 0 元**；不选付费规格即不产生费用 |
| xGPU 免费但有访问/时长上限、低频休眠 | 不把公开主链接压在高频 GPU 推理上；L0/L1 纯前端，无 GPU 依赖 |
| 云端兜底被滥用/超支 | 默认关 + 免费额度 + 超时回退；公开链接默认不带端点 |

## 7. 风险与回退

- **如果 DGX 未获批**：不影响交付——L0/L1 本就零依赖，L3 只是锦上添花；手记照实写"算力待批、端侧已可玩"。
- **如果云端端点不稳定**：默认关，玩家不配即纯端侧；开了也超时回退，不阻塞。
- **如果评审质疑"没接大模型"**：用 L0 的可解释面板 + 影子掌柜轨迹正面回应——"我们不接黑箱，我们摊开给你看"。
