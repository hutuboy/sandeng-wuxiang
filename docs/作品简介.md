## 短版（约 130 字 · 适合官网提交简介框）

《三更灯 · 无相客栈》是一款 AI 原生网页推理游戏。你是掌柜，一夜三客投宿，一人为「无相」。三位客人不是预设剧本，而是带五维量化状态、持久记忆与规则校验的 AI NPC——会因你逼得太紧而拂袖离店，真的关掉一条证据路径。灯只够点六回，问话、对簿、推演、指认，天亮前认出他。纯静态、离线可玩、零外部素材、seed 逐位可复现，MIT 开源。

## 标准版（约 420 字 · 适合创空间展示 / 手记开头）

《三更灯 · 无相客栈》是一款 **AI 原生网页推理游戏**：你是客栈掌柜，一夜三客投宿，其中一位是「无相」——他的证词与柜上物证对不上。灯只够点六回，天亮前必须把他认出来。

它最不一样的地方，是 **AI 不是皮肤，是规则本身**。三位客人由端侧 AI 决策引擎驱动：信任 / 好感 / 张力 / 疑心 / 定力五维量化状态，叠加人格权重做效用打分与 softmax 采样，再过一层规则掩码校验合法性。他记得你问过什么、问了几遍、用什么语气；信任不够死活不交关键物件，张力爆表会起身离店，第三夜疑心太高，无相会趁夜遁走——**每一次行为都真实改变游戏状态，而不只是输出一句话**。右侧「AI 决策轨迹」面板把特征、效用、掩码、状态增量全部实时摊开，评委不读代码就能验证。

推理也是真逻辑：四档难度对应四种破绽类型（有一处对不上 / 处处对不上 / 并非处处对不上 / 恰好只错一处），第三夜再叠一条「改口」行为破绽；残卷只给一句性质、不给式子，玩家得自己翻成对表的筛选。信息不够时有「对簿」——一盏灯换三人同答、最多三格，把中/高级档通关率从随机线拉到 88% / 83%，难度契约却一字未改。

三个 AI 各司其职：**AI 导演**带约束求解生成「唯一解」案件，**AI NPC** 决定信息如何流出，**影子掌柜**自动试玩 Agent 只走结构化接口通关并输出完整轨迹。每一夜由 seed 决定、逐位可复现。

全部立绘、夜景、纹理、音效由 SVG / Canvas / WebAudio 程序化生成，**零外部素材、零依赖、断网可玩**，纯静态双击即开。云端大模型只做可选润色——只改措辞、绝不改事实，挂了游戏照常玩。200 组种子自检 10/10、104 项浏览器验收全绿，代码 MIT 开源。

## 六大亮点（带可核验数据）

1. **AI 深度参与运行时，不是接个聊天 API。**
   三个 AI 分工：导演（约束求解生成可解案件）/ NPC（效用决策 + 规则校验 + 状态回写）/ 影子掌柜（自动试玩）。没有决策引擎，这一局根本跑不起来。

2. **NPC 行为可校验、可解释。**
   五维状态 × 人格权重 → 效用打分 → softmax → 规则掩码 → 状态回写，全链路在「AI 决策轨迹」面板实时摊开。`trust<35` 锁交心、`tension<70` 锁离店，每条规则都写明「为什么被锁」。状态扰动后一键重决策（200 种子实测平均 L1 距离 0.5451）。

3. **推理是真逻辑，不是对答案。**
   `js/logic.js` 把证词偏差写成原子命题，∧ / ∨ / ¬ / ⊕ 组成可嵌套表达式树；四档各一种破绽类型 + 第三夜「改口」行为破绽。出题器按破绽类型**反推**说法，「唯一解」是构造出来的——T7 用 720 组断言「满足判定者恰好一位」。

4. **信息经济是被量出来、再修好的。**
   「对簿」一盏灯换三人同答最多三格，把中/高级档通关率从 0.350 / 0.333 拉到 **0.883 / 0.833**，灯数等难度契约一字未改。高级档离随机指认（1/3）拉开 50 个百分点，并写进自检守护。

5. **可复现 + 工程硬核。**
   每一夜由 seed 决定，`?seed=xxx&night=2` 重开同一局；逻辑层与 DOM 解耦、Node 可跑。200 组种子自检 **10/10**（含唯一性 720 组、改口 480 组、对簿 288 组）、引导 **60/60**、难度 **44/44**、浏览器冒烟 **0 报错**、推演探针 **51/51**，全部可复跑。

6. **零依赖、离线可玩、100% 原创。**
   立绘 / 夜景 / 纹理 / 音效全部代码生成，无一张外部图片、一个字体文件、一段音频素材。纯静态、零构建、零密钥、断网可玩；云端润色只改措辞不改事实、每日调用限额（常态 200、评审期 500）、静默回退。MIT 完整开源。
