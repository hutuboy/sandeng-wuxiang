## 完整版

你是掌柜，一夜三客投宿，其中一位是「无相」——他的证词与柜上物证对不上。
灯只够点六回，天亮前必须把他认出来。

这不是一场「对答案」的游戏。三位客人由**端侧 AI 决策引擎**驱动：
信任、好感、张力、疑心、定力五维状态实时量化，每一句话都写入持久记忆；
温问养信任、逼问推张力、示物积疑心——信任不够，他拒绝交付关键物件；
逼得太紧，他拂袖离店，**真的关掉一条证据路径**；第三夜疑心过高，无相还会趁夜遁走。
每轮决策的特征、效用打分、规则掩码与状态回写，都在「AI 决策轨迹」面板里完整摊开，可校验、可复现。

案件由 **AI 导演**按约束求解生成：四档难度各对应一种破绽——
「有一处对不上 / 处处都对不上 / 并非处处对不上 / 恰好只错一处，就是『无相』」，
第三夜再叠一条行为破绽「改口」。残卷只给这一句话、不给式子，推理真正留给玩家；
「满足判定者恰好一位」是构造出来的，不是随机撞出来的。

玩法走**五步一窗**：点灯 → 问询 → 推演 → 指认 → 结案，每幕只开一扇窗；
灯不够用时可以「对簿」——一盏灯，三人就同一件物证同时开口，一次最多换三格。
五种结局、三夜通关评级、结算复盘卡，3 分钟一局，键鼠 / 触屏双端。

**影子掌柜 Agent** 只通过结构化接口与人走同一套规则自动试玩，
输出完整动作序列与信念轨迹；200 组种子 × 三夜自检 10/10 通过，
分档通关率：新手 98.3% / 初级 100% / 中级 88.3% / 高级 83.3%，最高档离随机线 50 个百分点。

云端大模型是**可选项**：独立代理只润色台词措辞、绝不改事实与判定，
每日 200 次闸门、到额静默回退；核心决策永不上云，断网照样玩。

## 核心亮点

1. **AI 不是皮肤，是规则本身。** AI 导演生成案件、AI NPC 决定信息如何流出、影子掌柜自动试玩——三个 AI 全部参与运行时，没有决策引擎这一局根本跑不起来。
2. **NPC 行为可校验、可解释。** 五维状态 × 人格权重 → 效用打分 → softmax 采样 → 规则掩码 → 状态回写，全链路在决策面板实时摊开；状态扰动后一键对比重新决策（200 组种子实测平均 L1 距离 0.5451）。
3. **推理是真的逻辑，不是对答案。** 原子命题 + ∧ ∨ ¬ ⊕ 表达式树藏在幕后，台前只给一句「破绽性质」；四档难度是四种逻辑结构，第三夜叠加「改口」行为破绽；信息不够用「对簿」补，难度契约一字未改。
4. **逐位可复现。** 每一夜由 seed 决定，`?seed=xxx&night=2` 重开同一局；结构化 API（`getState / listActions / dispatch`）对评测与二次开发开放，核心逻辑 Node 可直跑。
5. **工程自检武装到牙齿。** 200 组种子 10/10 项不变量（含 720 组判定唯一、480 组改口、288 组对簿）+ 浏览器冒烟 0 报错 + 引导 60 项 + 难度 44 项 + 推演探针 51 条断言；预置缺陷 F-01 可随时复现「修复前 vs 修复后」。
6. **零依赖、100% 程序化原创。** 立绘、夜景、纹理、音效全部由 SVG / Canvas / WebAudio 代码生成，无一张外部图片、一个字体文件、一段音频素材；双击 `index.html` 即玩，MIT 完整开源。
