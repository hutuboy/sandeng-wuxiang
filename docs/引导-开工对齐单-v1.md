# 新用户引导 · 开工对齐单 v1（制作人）

**取代**：无（首版）　|　**状态**：已下发三份专业规格单，待汇编

## 需求复述

在现有《三更灯 · 无相客栈》游戏界面内加一套**纯前端**的新用户操作指引：分步气泡＋高亮聚焦，带第一次进来的玩家从开局走到「会问第一句话」。

制作人代用户做的假设：

1. 首次进入自动触发，localStorage 记住已完成；
2. 可跳过，顶栏常驻「再看一次」入口；
3. 不改任何 AI 逻辑 / 案件生成 / 计分；
4. 原生 HTML/CSS/JS，零新依赖；
5. 移动端同可用。

## 本轮范围

**做**：引导层、步骤定义、锚点定位、遮罩高亮、进度指示、跳过/重看、移动端、可复跑验收、实际截图。

**不做**：改核心玩法与 AI、加后端、加外部素材、自动重新发布线上（已有 live link，覆盖需用户点头）。

## 档位与步骤

**迭代档**（v1.0.0 已有可运行版本上改需求）→ 盘影响面 → 设计/视觉/QA 并行出规格 → 主程序集成 → 制作人跑浏览器冷启动验收＋看帧 → 提交＋新 tag。

跳过阶段 1/2/3/4/5 完整五阶段：本轮是已有版本上的单功能迭代，按「迭代协议」走，不走新项目全流程。
