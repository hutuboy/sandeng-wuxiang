# 演示视频分镜脚本（16 秒 / 25fps / 1280×800）

> 成片：`docs/演示视频.mp4`　|　重录：`node tools/make-demo.cjs`
> 录制方式：Edge headless + CDP `Page.startScreencast` 捕获真实渲染帧，按帧号驱动操作，libx264 编码。
> 不是截图轮播，画面里的灯笼、浮尘、状态条与面板数值都是实时渲染。

| 时间 | 帧号 | 画面 | 动作 / 想让人看到什么 |
| --- | --- | --- | --- |
| 0.0–2.5s | 0–62 | 封面：三更灯标题、灯笼夜景、参赛标识、三个入口按钮 | 题材与第一印象；证明是完整作品而非 Demo 页 |
| 2.5–3.8s | 62–95 | 点「开始守夜」→ 对局首屏 | 三客立绘、五维状态条、柜上物证、六盏灯、话头卡；底部提示 |
| 3.8–5.4s | 96–134 | 选客人 1 → 温问「关键话头」 | 对话区出现 NPC 回答；右侧 AI 决策轨迹同步展开：特征、效用条、规则校验、状态回写、记忆 |
| 5.4–6.9s | 134–172 | 选客人 2 → 同一话头 | 证词簿累积；开始出现措辞差异（含糊 ≠ 说谎） |
| 6.9–8.3s | 172–208 | 选客人 3 → 同一话头 | 三条证词齐了，矛盾可见；物证真值仍在左侧 |
| 8.3–9.9s | 208–248 | 点「重新决策对比」弹窗 | 状态扰动后合法动作集与概率分布改变——AI NPC 专项奖硬指标的可视化证据 |
| 9.9–11.8s | 248–296 | 关弹窗 → 「摊开比对」弹窗 | 物证真值 vs 三人证词并排，展示推理玩法 |
| 11.8–12.8s | 296–320 | 关弹窗 → 点「点灯 · 指认无相」 | 指认弹窗：三位客人 + 置信度（明确说明不是答案） |
| 12.8–16.0s | 320–400 | 指认真凶 → 结算页 | 结局标题、得分、真相摊开（谁说了什么、真值是什么）、置信度条、三夜入口 |

## 配套文案（可用于视频简介 / 创作手记）

> 《三更灯 · 无相客栈》16 秒实机演示。
> 一夜三客，一人为「无相」；三位客人由端侧 AI 决策引擎驱动：
> 量化状态、持久记忆、规则校验，会记住你问过的每句话，也会因为你逼得太紧而离店。
> 右侧面板把每一步决策的打分与合法性校验实时摊开。
> 纯静态、离线可玩、MIT 开源。

## 重录前检查

- `.tooling/node_modules/playwright-core` 存在，本机 Edge 路径为 `C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe`
- `python -c "import imageio_ffmpeg; print(imageio_ffmpeg.get_ffmpeg_exe())"` 能返回 ffmpeg 路径
- 帧率 / 总帧数在 `tools/make-demo.cjs` 顶部 `FPS` / `TOTAL` 调整
- 录完用 `ffmpeg -ss 6 -i <视频> -frames:v 1 out.png` 抽帧复核第 6 秒为对局、第 14 秒为结算
