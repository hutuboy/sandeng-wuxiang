# 《三更灯 · 无相客栈》社媒宣传片 · 制作规划 v1

> 目标：一条 **25–32s 竖屏（1080×1920 / 9:16）** 社交媒体宣传片，同时达成「吸引观众」与「教会观众」。
> 原则：**零复用**旧录屏与旧截图；画面全部本轮新产。
> 日期：2026-11-11

---

## 0. 结论先行（一页纸）

- **结构**：吸睛开场（0–5s）→ 核心展示 + 教学（5–24s）→ 行动引导（24–30s）。
- **素材**：`OiiOii AI 生成氛围帧`（新，无旧素材）+ `当前版本实机新录屏/新截图`（新捕获）+ `ffmpeg` 动效合成 + `edge-tts` 中文配音。
- **资源现实（2026-11-11 实测）**：
  - 可灵 AI：**可用额度 = 0**（NORMAL，0 灵感值）→ 无法生成。
  - OiiOii：已授权，**60 积分（free 档）**；**所有视频模型均为会员专享 → 不可用**；可用：图片（HunYuan 3.5 **5 分/张**、Oii Image 2.6 7 分、Seedream 5.5 10 分）、配音（Oii Eleven V4 **0.2 分**）。
  - 内置 VideoGen：5s ≈ 50–100 积分（付费）；ImageGen：5–10 积分/张（付费）。
  - 美图设计室：CLI 1.0.79 可用，需美豆（付费）。
- **取舍结论**：**真·AI 视频全部被付费墙挡住**。零成本可落地的最高质量路线 = **AI 图片（OiiOii 5 分/张）+ ffmpeg 运镜/调色/字幕**；真正 AI 视频片段留待充值后作为 v2 升级。

## 2. 调用顺序与工作流衔接

```
[Stage 0 立项]  规划本文档 → 确定结构/时长/画幅/风格母版
      │
[Stage 1 风格母版]  定色板/LUT/字体/字号阶梯/运动与转场语法/音频响度 → style.json
      │
[Stage 2 素材生成]  OiiOii 生 4 张 9:16 氛围帧（hook/转场/物证/CTA）
      │            ＋ 实机新捕获（当前版本 headless 录屏/截图，非旧素材）
      │            ＋ edge-tts 旁白（分段）→ 拼接并对齐
      │
[Stage 3 归一化]  所有素材统一 → 1080×1920 / 25fps / yuv420p / 统一调色 → 进合成池
      │
[Stage 4 合成]    per-clip ken-burns 运镜 + 分级字幕 + xfade 转场 → 主时间线
      │
[Stage 5 混音]    旁白 atempo 对齐 + 极简氛围垫（或静音兜底）→ 响度归一到 −14 LUFS
      │
[Stage 6 质检]    ffmpeg -i 核验流规格 / 抽帧看画面 / 音量峰值检查
      │
[Stage 7 交付]    docs/宣传视频-社媒竖版.mp4 + 封面帧 + 交付清单更新
```

**衔接契约**：每段产物命名 `s{NN}_{角色}.{ext}`（如 `s01_hook.png`、`s03_game.mp4`），统一放 `.tooling/promo2/`；风格参数只从 `style.json` 读，禁止各段各调一套色。

## 3. 如何保证「美观、画面协调、风格统一」

**做法：先立母版，再批量套用；所有素材在合成前先归一化。**

### 3.1 视觉母版（style.json 单一来源）
- **色板**：墨黑 `#0d0b0a`（底）/ 灯笼暖金 `#f0b429`、高光 `#ffe9b0` / 朱砂红 `#b23a2e`（强调）/ 冷月青 `#5c7a8a`（对比）。
- **调色**：统一曲线——提暗部青、压高光暖、+对比 1.12、饱和 1.15、轻微暗角（vignette）。
- **字体**：`simhei.ttf`（黑体，粗、识读强）；**字号阶梯** 76/48/40/32；字距固定；安全区上下各留 12%。
- **运动语法**：ken-burns 统一「缓入缓出」推近，速度 ≤ 6%/段；文字入场统一 fade+4px 上移。
- **转场语法**：**只用两种**——`fade`(0.35s) 与「灯光过曝白闪」(0.2s)；禁止花哨转场。
- **画幅/帧率**：1080×1920、25fps、yuv420p（全片强制一致，避免 xfade 崩）。
- **音频**：旁白 −14 LUFS 基准；垫乐 −24 LUFS 低伏；峰值 ≤ −1 dBFS。

### 3.2 协调保障机制
1. **归一化前置**：任何素材进时间线前，先统一到 1080×1920/25fps/yuv420p + 同一调色链。
2. **单一字幕层**：所有文字由 ffmpeg `drawtext` 生成，字体/颜色/描边全局一套，杜绝「每段字体不一样」。
3. **节奏表**：每段时长、镜头数、字幕字数写死进脚本，避免临场拍脑袋导致忽快忽慢。
4. **抽帧复核**：合成后按秒抽 8 帧人工/视觉复核色温、构图、字幕遮挡。

## 4. 有限资源下的取舍与优化

| 维度 | 真·AI 视频（可灵/VideoGen） | AI 图片 + ffmpeg 运镜（本片选此） |
| --- | --- | --- |
| 成本 | 0 额度/50–100 积分/5s（付费） | OiiOii 5 分/张（免费档已有 60 分） |
| 可控性 | 低（易跑偏、需多次重roll） | 高（构图/时长/字幕全可控） |
| 一致性 | 差（多段风格漂移） | 好（同一母版批量套） |
| 风险 | 高（失败即浪费额度） | 低（失败可重跑，0 元） |

**取舍要点**：
1. **「冲击力」不靠生成视频，靠构图 + 调色 + 运镜 + 节奏 + 音效**——静态高质量帧 + 缓推 + 白闪，观感并不输廉价 AI 视频。
2. **AI 只花在「最难拍」的 4 帧氛围**（雨夜客栈、灯灭、物证特写、破晓空店），其余用实机新捕获保真。
3. **玩法演示必须实机**——AI 画不出真实 UI，「教玩法」只能靠当前版本真录屏，这是不可替代的。
4. **配音用 edge-tts**（0 元、可复跑），不占用 OiiOii 积分；OiiOii 配音仅作备选。
5. **BGM 用极简合成垫或静音兜底**，不引入版权风险，也不为一段氛围音乐付费。
6. **预算封顶**：OiiOii ≤ 20 分（4 张），其余 0 元；不触发任何付费。
