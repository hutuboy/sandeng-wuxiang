## 一、风格定义

### 1.1 同源约束

引导层是**叠在现有界面上的临时层**，不是新皮肤。取值必须来自 `style.css` 既有体系：

- **色板**：只用既有变量。引导层**唯一强调色 `--amber` / `--amber-lt`**（灯）；`--jade` / `--crimson` / `--violet` 是玩法状态色，引导层不得占用。
- **圆角**：沿用 `3px`（`.btn`）/ `4px`（`.panel`）/ `5px`（`.modal`）。高亮框与气泡统一 **4px**；**不使用 10px 及以上大圆角**。
- **字体**：标题 `var(--serif)`、正文 `var(--sans)`、数字 `ui-monospace,Menlo,Consolas,monospace`（对齐 `.tb-lamp-label` L134）。不引入字体文件。
- **材质**：半透明暗底 + 1px 琥珀描边 + 极轻琥珀外辉光，与 `.guest-card.selected`（L181）、`.lamp.on`（L131）同源；不用玻璃拟态高光、渐变按钮、投影卡片。
- **明暗**：遮罩把全局压到「夜」，琥珀高亮是唯一光源；气泡是「灯下的一张纸」。
- **可读性**：正文 `--ink` 对气泡底 ≥15:1；次要文字最低 `--muted`（≥7.6:1）；`--dim`（≈4.0:1）**禁止承载引导正文 / 关键信息**，只用于纯装饰。
- **颜色不得成为唯一信息载体**：进度当前态、按钮禁用态须同时有尺寸 / 填充 / 描边 / 光标 / 文本差异。
- **气泡文案硬约束（引用设计案 2.1）**：正文 ≤40 字、2–3 行；**气泡内不得出现表格、参数、章节标题、快捷键清单**；视觉侧不得在气泡里加任何键盘提示条。
- **零外部资源**：给形状、颜色、尺寸比例与合批建议，不给贴图路径。

### 1.2 视觉语言 · 五项样式契约

#### (A) 遮罩 `.guide-mask`

| 属性 | 契约值 | 说明 |
| --- | --- | --- |
| 暗色 | **`rgba(5,4,9,.72)`**（区间 `.68`–`.78`，设计案 3.1） | 与既有 `.modal-mask` 的 `rgba(5,4,9,.78)`（L296）同色系、观感衔接；近黑不泛紫，不用纯黑、不用 `--crimson` |
| 定位 | `position:fixed; inset:0` | 视口坐标系，与洞 / 气泡共用 |
| **G1（整屏步）** | **无高亮洞**，全屏满暗 `rgba(5,4,9,.72)`；气泡居中卡、箭头隐藏 | 设计案第二章：G1 锚点 `#screen-game` 整屏、无洞 |
| 单洞步（G2 / G3 / G4 / G6） | `.guide-hole` 上 `box-shadow:0 0 0 9999px rgba(5,4,9,.72)`，或用 SVG `<mask>` 白底 + 黑色圆角矩形挖空 | 洞跟随 `getBoundingClientRect()`，圆角 `4px`；实现采用 SVG mask，等效 |
| 多洞步（G5 主副锚、`#btn-help` 常驻豁免洞） | 4 片 / 多矩形拼接，或 SVG `<mask>` 多个黑矩形 | 设计案 3.4 允许；避免多个 9999px 阴影叠加导致双重压暗 |
| 洞几何 | `锚点 getBoundingClientRect()` 外扩 `8px`（≤400px 降 `6px`），`radius 4px` | 外扩避免描边贴住内容 |
| 洞边缘 | 1px `var(--amber)` 描边 + 琥珀辉光（由 `.guide-hole` 承担） | 不硬切 |
| **指针（唯一命中层）** | 暗色绘制层 `pointer-events:none`；**唯一命中层** `position:fixed; inset:0; pointer-events:auto; background:transparent`（本规格与实现采用 `.guide-scrim`）覆盖整屏**含高亮洞区与 `#btn-help` 豁免洞** | 设计案 3.4 实现中立：唯一命中层可为全屏 scrim 兼任，也可为等效独立 catch，**不强求元素名**；消费式承接，**不是点击透传** |
| **矩形命中判定（设计案 3.4）** | 唯一命中层的 click handler 用 `#btn-help` 豁免洞 rect 做坐标判定：**命中 rect → 只写 `skipped` ＋ 收尾**（并 `preventDefault()/stopPropagation()`）；**命中 rect 之外 → 一律吞掉 no-op**（不跳过、不推进、不下传） | **禁止「点遮罩任意处即跳过」** —— 会让玩家误触退出，并使「每步常驻跳过」失去意义 |
| 淡入 | `opacity 0→1, .2s ease` | reduced-motion 下取消 |

> **G1 与常驻豁免洞不冲突**：`#btn-help` 的常驻豁免洞是「**不铺暗色的可见性切口**」，**不是高亮洞**（不画琥珀框、不参与步骤锚点、不进 `rectsFor(step)` 的高亮集合）。因此「G1 全屏满暗 / 无高亮洞」成立 —— G1 只是除该可见性切口外全屏铺暗，仍无任何高亮框。

#### (B) 高亮框 `.guide-hole` + 辉光

- `.guide-hole`：`position:fixed; box-sizing:border-box; border:1px solid var(--amber); border-radius:4px; pointer-events:none; background:transparent`。单洞时兼承载 9999px 暗影（静态，不参与动画）；实现改用 SVG mask 时由 `.guide-hole` 只承担描边与辉光。
- 琥珀辉光：`box-shadow:0 0 0 1px rgba(232,164,92,.35), 0 0 18px 4px rgba(232,164,92,.22), inset 0 0 12px rgba(232,164,92,.06)`（复刻 `.guest-card.selected` L181）。若用独立子元素（如 `.guide-glow`）承载动画以避免抖动到 9999px 暗影，亦属等效实现，不强求类名。
- 呼吸 `@keyframes guide-breathe`：`2.4s ease-in-out infinite`（对齐 `.tag.live` `pulse 2.4s` L69，全站同拍）；仅对辉光半径与透明度交替：0% `18px/.22` → 50% `26px/.34` → 100% `18px/.22`。多洞共用同一 `animation-delay`，禁止错拍。
- reduced-motion：显式 `animation:none` + 静态辉光 `.28` 常亮（不能只靠 L364 全局 `animation-duration:.01ms`，否则可能停在非期望末帧）。
- 焦点时叠 `outline:2px dashed var(--amber-lt); outline-offset:3px`。
- 洞内不放文字 / 图标；高亮框只做指示。
- **结束态可砍项**：`#topic-row` 呼吸描边 `2s`（设计案 3.1 / 七），不拦截、不耗灯；视觉层实现，可砍。

#### (C) 气泡 `.guide-bubble`

- **不直接复用 `.panel` 类**（其 `overflow:hidden` L74 会裁掉箭头、`::before` 纹理干扰正文）；只复用四个值：`background:var(--panel)`、`border-radius:4px`、`backdrop-filter:blur(10px)`、升级后的 `border:1px solid var(--line-2)`。`overflow:visible` 以容纳箭头。
- 外阴影 `0 12px 32px rgba(0,0,0,.5)`（沿用 `--shadow` 量级）。
- 顶部「灯芯」细线：`.guide-bubble::before`，`height:2px` `linear-gradient(90deg,transparent,var(--amber),transparent)`，纯 CSS。
- **宽度 `min(92vw, 340px)`**（设计案 3.1 终值，区间 280–360px；**桌面与 ≤760px 同值，不设 320px 移动覆盖**）；最大高度 `min(60vh,420px)`；内边距 `16px 18px`（≤760px `14px`）；节奏 8 / 12 / 16px。
- 正文超 3 行时**气泡内部滚动**（`overflow-y:auto`），不整体放大、不压顶栏 / 操作台。
- 眉标（实现为 `.guide-label`）：`12px` / `--muted` / `var(--sans)`，含「操作指引」标识与进度（格式见 (D)；对应设计案 5.1-1）。
- 标题 `.guide-bubble__title`：`var(--serif)` / `17px`（≤760px `16px`）/ `600` / `letter-spacing:.04em` / `--amber-lt`（对齐 `.modal-head h3` L300）。
- 正文 `.guide-bubble__body`：`var(--sans)` / `14px`（≤760px `13px`）/ `line-height:1.7` / `--ink`；次级 `--muted`、注释 `--label`。**文案一律取自设计案第二章，本规格只定排版层级。**
- 箭头 `.guide-bubble__arrow`：`7px` 等腰直角，`background:var(--panel)` + `border-right/border-bottom:1px solid var(--line-2)` + `rotate(45deg)`；`.is-top/.is-bottom/.is-left/.is-right` 切换方位；**G1 隐藏**。
- 定位 `position:fixed`，距洞 `12px`；优先洞下方，空间不足翻上方，再左右避让。**禁止覆盖 `.topbar`、`.tb-right`、`#tb-lamps`、`.action-dock`**（设计案 5.4-3 / 四-③）。
- G6（`.topbar` 单洞）气泡**居中偏下**，不压顶栏；G1 居中卡。
- 入场 `guide-pop .2s ease`（opacity + `translateY(6px)`）；reduced-motion 下 `animation:none`。
- 气泡内不放插画 / 图标 / 快捷键清单。

#### (D) 进度指示 `.guide-progress`

- 格式统一「**第 N / 6 步**」（设计案第二章 / 六章）；**步数终值 `6`**，来自设计案 3.1【契约】，与步骤总数同源，视觉侧不再留空。文本 `12px` / `--muted` / `font-variant-numeric:tabular-nums`。
- `6` 个 `.guide-dot`：`8px` / `border-radius:50%` / `border:1px solid var(--line-2)` / `background:transparent`。
  - `.is-todo` 空心；`.is-done` 实心 `--amber` 无光；`.is-active` 实心 `--amber-lt` + 直径 `10px` + `box-shadow:0 0 8px rgba(255,201,135,.5)`。
  - **颜色不是唯一载体**：当前＝放大 + 实心 + 发光（三重），已完成＝实心无光，未到＝空心。
- 布局 `display:flex; align-items:center; gap:8px; flex-wrap:wrap`；≤400px 点缩至 `6px`、`gap:4px`，`第 N / 6 步` 换行到第二行右对齐；禁止横向溢出。
- 无障碍：`aria-current="step"` 标在当前点，容器 `role="group"` + `aria-label="第 N / 6 步"`，文本 `aria-live="polite"`。

#### (E) 按钮组 `.guide-actions`

- **不新建按钮基底**：复用 `style.css` L41–55 的 `.btn` / `.btn-primary` / `.btn-ghost`（含既有 `:hover` / `:active`）与 `button:disabled`（L25）。
  - 「下一步」→ `.btn.btn-primary`；末步「知道了 · 去问第一句」用 `.is-last` 修饰（**文案由设计案定**）。
  - 「上一步」→ `.btn.btn-ghost`；首步 `:disabled`。
  - 「跳过」→ `.btn.btn-ghost` + `.guide-actions__skip` 弱化：去填充、去描边、`--muted` 字、`border-color:transparent`，hover 转 `--ink`；置于最右，与主按钮间距 ≥12px 防误点。
- **触控目标 ≥44×44 px（区间 44–48，设计案 3.1）**：`.guide-actions .btn{min-height:44px; min-width:44px}`，全档位生效（非仅移动端）。
- 布局 `display:flex; gap:8px; flex-wrap:wrap`；主按钮 `margin-left:auto`；与进度区间 `12px` + `1px solid var(--line)` 细线。
- 拦截例外（设计案 3.1 / 3.4）：**仅**气泡内三个按钮、`#btn-help`（引导期语义＝跳过，经唯一命中层矩形判定）、`#toast`（仅展示）可响应；其余一律不响应。**禁止「点遮罩任意处即跳过」**。点击 / 按键的流程后果归设计案 3.2 / 3.4，视觉侧不定义。

- **选择器存在性（设计案 5.0）**：`#action-dock` **不存在**，操作台是 class `.action-dock`；`.topbar` / `.game-grid` / `.col-center` / `.tb-center` / `.tb-right` 均为 class。所有视觉选择器按真实存在性书写，勿用不存在的 id。
- **穿透点击：全阻断，不穿透**（设计案 3.4）。唯一命中层全屏 `pointer-events:auto` 覆盖整屏**含高亮洞区域与豁免洞**；暗色绘制层、`.guide-hole` 一律 `pointer-events:none`；`.guide-bubble` 是唯一常规可交互区。挖洞只改像素、不改命中，洞内的 `#topic-row` / 客人卡 / 吸底操作台一律不可点 —— 保障六盏灯一盏不动。
- **矩形命中判定（设计案 3.4，唯一例外）**：`#btn-help` 豁免洞区域不绘制暗色背景；唯一命中层的 click handler 用该 rect 做坐标判定 —— **命中 rect → 只写 `skipped` ＋ 收尾**（`preventDefault()/stopPropagation()`，**不派发到 `#btn-help`、不下传游戏**）；**命中 rect 之外 → 一律吞掉 no-op**（不跳过、不推进、不下传）。**禁止「点遮罩任意处即跳过」**。这是消费式捕获，不是点击透传。
- **键盘拦截与快捷键（硬约束，设计案 3.4）**：引导层不是 `.modal-mask`，`main.js` 冒泡 `keydown` 只在存在 `.modal-mask` 时提前 return，故 `Q/W/E/R/T/L/1/2/3/A/C` 会直接 `doAsk()` / `doListen()` **耗灯**。必须由主程序在 `document` **capture 阶段**注册 `keydown`，对除引导自身快捷键外的全部按键 `stopImmediatePropagation()`，完成 / 跳过时注销。引导自身快捷键由 capture 监听消费、不下传游戏：**`←`＝上一步、`→` / `Enter` / 空格＝下一步（G6 为末步动作）、`Esc`＝跳过**。**视觉侧只保证键位可达、焦点可见、不吞掉引导自身快捷键，不实现拦截、不定义点击 / 按键的流程后果**（后果归设计案 3.2 / 3.4）。
- **是否遮挡 `#btn-help`：不遮挡（明确结论，按设计案 5.4 / 5.0 修订）**。引导期间 `#btn-help` **可见 ＋ 点击可达（经唯一命中层矩形判定）**，语义＝跳过（设计案 3.1 / 3.2 / 5.4）。实现：**不设任何子级 z-index**；暗色遮罩为 `#btn-help` 矩形开**常驻豁免洞**（该处不绘制暗色背景，使「?」透出可见）＋ 唯一命中层做矩形命中判定（命中→跳过、矩形外→吞掉）。**`#btn-help` 引导期不接收 DOM click，也不进 3.4 的气泡焦点陷阱**；键盘跳过走 `Esc` 与气泡「跳过」。**视觉侧只保证可见 / 点击可达，点击后果归设计案 3.2 / 3.4。** 气泡定位禁止覆盖 `.tb-right` 与 `#tb-lamps`。
- **收尾（设计案 5.1-3）**：完成 / 跳过 / 异常收尾时，**必须**移除 `#guide-layer` 节点（**含唯一命中层与豁免洞**）、注销 capture 键盘监听、恢复 `#btn-help` 原样式与 3.3 帮助菜单语义、清除滚动锁；结束后点「?」恢复帮助菜单。

  > **堆叠上下文结论（设计案 5.0，已否决「提升层级」方案）**：`#guide-layer` 挂 `body`，与 `.screen`(z-2) 在**根堆叠上下文**中比较；而 `#btn-help` 被包在 `.topbar`(z-5，flex item 亦建上下文) → `.screen`(z-2) 两层上下文之内，给子元素设任何 z-index 只在其父上下文内生效，**永远无法越过 z-20 引导层**。「提升 `.screen` / `.topbar` 层级」方案已**否决**（整体提 `.screen` 会让游戏画面盖过遮罩、破坏高亮聚焦；单独提 `.topbar` 又逃不出 `.screen` 上下文）。采用「常驻豁免洞 ＋ 唯一命中层矩形判定」：暗色遮罩在 `#btn-help` 矩形处不绘制背景使其透出可见，点击由唯一命中层消费并映射为「跳过」，二者都在引导层内闭环，语义按 3.2 不变。**不得让实现者误以为 `#btn-help` 自身在引导层之上、能直接收 click** —— 那会漏掉命中判定，使「?」变成死按钮、跳过路径少一条。

- **与弹窗 / toast 共存**：引导层 **20 < `.modal-mask` 30**，与首版（40）相反 —— 即便异常弹窗也会盖住引导，故启动前置守卫「`document.querySelector('.modal-mask') === null`」且引导期间**禁止任何 `UI.openModal`**（设计案 3.1 / 5.3）。`#toast` 50 > 20，提示正常显示不受影响。
- **G6 锚点变更（设计案 v1）**：原 v0 的 `#tb-lamps + #col-right + #btn-accuse` 三锚点已删，改为 **`.topbar` 单洞**（覆盖灯组与「AI」开关），降级锚点 `.tb-center`。洞为全宽 58px（≤760px 52px）带，上下外扩 8px 后需 clamp 在视口内；气泡居中偏下、不压顶栏。`#col-right` / `#ai-panel` / `#btn-accuse` **在 v1 中不是任何步骤的锚点**（设计案 2.1-L75 / 5.0）。
- **G5 锚点**：主锚 `#statement-list` + 副锚 `#clue-list` **仅同屏可见时并列**；≤400px `.col-left` 纵向时只高亮主锚（降级为单洞）。逐行锚点与降级锚点见设计案第二章，本文件不复述。

### 1.5 挖洞在滚动容器与 `position:fixed` 吸底操作台上的定位要求

1. **统一视口坐标系**：遮罩 / 洞 / 气泡 / 唯一命中层全部 `position:fixed`，矩形取 `getBoundingClientRect()`（本身即视口坐标）。**禁止叠加 `window.scrollY` / `pageYOffset` / 容器 `scrollTop`** —— 吸底操作台最常见的偏移 bug。
2. **可见性前置判定（设计案四-④ · 裁决 C-8）**：**禁用 `offsetParent !== null`** —— ≤760px 时 `.action-dock` 为 `position:fixed`，其 `offsetParent` 恒为 `null`，会把 G3/G4 核心锚点误判为不可见。统一判据为 `display!=='none' && visibility!=='hidden' && getClientRects().length>0 && rect 宽高 > 0`；不可见即走设计案第二章降级锚点，不生成洞、不占位。
3. **先滚入再取矩形**：`body{overflow:hidden}`（L21）、`.screen{overflow:auto}`（L36）、≤760px `.game-grid{overflow:auto}`（L327），且 `.statement-list`（L164）/ `.clue-list`（L152）/ `.dialogue`（L203）为独立滚动容器。每步渲染前先 `scrollIntoView({block:'center', behavior:'auto'})`，**随后锁定滚动**（遮罩拦截 touch / wheel），再读 `getBoundingClientRect()`，避免高亮框与锚点错位（设计案四-②）。
4. **`position:fixed` 锚点直通**：≤760px `.action-dock` 为 `position:fixed; left:8px; right:8px; bottom:8px; z-index:8`（L349），其 rect 直接可用，与普通锚点走**完全相同**分支，不做任何补偿；其内 `#tone-group` / `#topic-row` 同理。
5. **重算时机（设计案四-⑤）**：切步、`resize`、横竖屏切换均重算高亮框、气泡位置**与 `#btn-help` 豁免洞 / 命中判定矩形**，**不重置步骤、不写值**；监听须 `document.addEventListener('scroll',fn,true)`（capture，因滚动在容器），统一 `requestAnimationFrame` 节流。洞矩形与视口求交并 clamp（非负宽高、不超视口）。
6. **命中判定矩形**：= `#btn-help.getBoundingClientRect()` 外扩 `4px`，与常驻豁免洞同源、同步重算；**只作为 JS 坐标判定数据，不新建任何 DOM 元素**；`resize` 后不得残留旧矩形造成误触或漏点。
7. **≤1180px**：`#col-right{display:none}`（L320），只有加 `.force-show` 才变右侧抽屉（`top:58px; z-index:12`）。v1 已把 `#col-right` 从锚点中删除，无需为隐藏元素降级；`.force-show` 若出现，其 fixed 锚点走视口直通分支，仍在 z-20 之下被正常覆盖。
8. **≤400px**：`.col-left` 纵向、列表 `max-height:120px`（L358–363），洞 padding 降至 6px，G5 只保留主锚单洞。
9. **性能 / 合批**：全部引导元素挂在同一 `#guide-layer`，共用一套 `--guide-*` 变量；并发洞上限 ≤3（主锚 + 副锚 + `#btn-help` 豁免洞）；只对 `.guide-bubble` 用 `will-change:transform,opacity`，**不给每个洞加 `will-change` 或独立 `box-shadow` 动画**（移动端合成层爆炸）。零新文件、零图片请求。

### 3.3 移动端（≤760px）规则

**真实层级与几何（实测值，不推测）**：`.topbar` `z-index:5`、高 **52px**（L325）；`.action-dock` `position:fixed; left:8px; right:8px; bottom:8px; z-index:8`（L349）；`.game-grid` 纵向堆叠且 `overflow:auto`、`padding-bottom:132px`（L327 / L348）；`.col-right.force-show` `position:fixed; top:58px; z-index:12`（≤1180px，L321）；≤400px `.col-left` 纵向、列表 `max-height:120px`。引导层 z=20 高于以上全部、低于 `.modal-mask` 30 与 `#toast` 50。选择器存在性以设计案 5.0 为准（无 `#action-dock`）。

- **气泡宽度**：`min(92vw, 340px)`（设计案 3.1 终值，**桌面与窄屏同值，不设 320px 移动覆盖**）；内边距 `14px`；标题 `16px` / 正文 `13px`（对齐 L324 `body{font-size:13px}`），行高 ≥1.7；92vw 留出 4vw 横向余量，`env(safe-area-inset-left/right)` 由 fixed 定位偏移兜底。**正文超 3 行气泡内部滚动**。
- **安全区与禁入区**（`viewport-fit=cover` 已开，index.html L5）：
  - 顶部禁入区 = `env(safe-area-inset-top) + 52px + 8px`（≤760px 顶栏 52px）。
  - 底部禁入区 = `env(safe-area-inset-bottom) + 8px + 操作台实测高度 + 12px`。操作台高度**动态取 `.action-dock.getBoundingClientRect().height`**，禁止写死 L348 的 `padding-bottom:132px`（那是内容留白，非操作台实高）；同时把 `#toast` 的 `bottom:34px`（L314）计入该带。
- **气泡位置（设计案四-③硬约束）**：二选一 —— ①「贴顶固定条」，须**下移过 52px 顶栏**；②「贴底但**上移 ≥140px**」。**不得覆盖 `.action-dock`、`.topbar`、`#tb-lamps`、`.tb-right`（含 `#btn-sound` / `#btn-ai-toggle` / `#btn-help`）**。G6 `.topbar` 单洞时气泡居中偏下，不压顶栏；G1 仍居中卡。
- **`#btn-help` 可见 ＋ 点击可达（经命中判定）**：常驻豁免洞同样适用于窄屏（顶栏 52px 带内）；`resize` / 横竖屏须**同步重算豁免洞与命中判定矩形**（设计案四-⑤），不重置步骤、不写值；气泡贴顶时不得盖住 `.tb-right`；结束移除豁免洞与唯一命中层。**`#btn-help` 引导期不接收 DOM click、不进气泡焦点陷阱**，键盘跳过走 `Esc` 与气泡「跳过」。
- **滚动与定位**：每步先 `scrollIntoView({block:'center',behavior:'auto'})` 再取 rect，**随后锁定滚动**（遮罩拦截 touch / wheel）；`#toast`（z=50）在引导层之上属预期。
- **进度点换行**：`.guide-progress{flex-wrap:wrap; gap:6px; max-width:100%}`；容器 < 260px 时「第 N / 6 步」`flex-basis:100%; text-align:right` 换到第二行，圆点保持单行；仍超宽则点缩 `6px`、`gap:4px`；`overflow-x:hidden` 兜底，禁止溢出 / 截断数字。
- **按钮组**：`flex-wrap:wrap`；`.guide-actions .btn{flex:1 1 auto; min-height:44px; min-width:44px}`（≤48px 上限）；「跳过」放不下时换行到第二行右对齐，与主按钮间距 ≥12px 防误点。
- **≤1180px**：`#col-right` 默认 `display:none`；`.force-show` 抽屉（`top:58px` / `z-index:12`）若在引导中出现，走视口直通分支，仍在 z-20 之下。v1 已把 `#col-right` 从锚点删除，无需为隐藏元素降级。
- **≤400px**：洞 padding 6px；G5 只保留主锚单洞，避免双洞离屏。
- **穿透策略不变**：全阻断，唯一命中层覆盖全屏含吸底操作台、洞区与豁免洞；仅气泡内按钮与命中 `#btn-help` rect 的点击可响应，**矩形外一律吞掉 no-op**。

> L364–366 已有全局 `*{animation-duration:.01ms !important;transition-duration:.01ms !important}`；引导层仍须显式补 `.guide-hole{animation:none}` 与 `.guide-bubble{animation:none}`，否则动画可能停在非期望末帧。降级只取消「动」，**不取消**状态差异、焦点环、`aria-live` 播报。

**键盘可达（映射以设计案 3.4 为准，视觉侧不复述流程后果）**

- `.guide-bubble`：`role="dialog"`、`aria-modal="true"`、`aria-labelledby` 指标题、`aria-describedby` 指正文；步骤切换后焦点移入气泡（`tabindex="-1"` 或主按钮）。气泡容器自身 `:focus` 可不显示外框，但**气泡内可聚焦控件的 `:focus-visible` 外框必须保留**。
- 焦点陷阱：Tab / Shift+Tab 只在气泡内**已启用**按钮间循环，不得逃到底层；引导结束焦点归还触发前节点（主程序记录）。**`#btn-help` 不进焦点陷阱**；键盘跳过走 `Esc` 与气泡「跳过」。唯一命中层（`.guide-scrim`）设 `aria-hidden="true"`，不进 Tab 序列。
- 引导自身快捷键由 capture 监听消费、不下传游戏：**`←` 上一步；`→` / `Enter` / 空格 下一步（G6 为末步动作）；`Esc` 跳过**；其余按键一律吞掉。视觉侧只保证**键位可达、焦点可见、不吞掉上述引导自身键位**；不实现拦截、不定义按键 / 点击的流程后果（归设计案 3.2 / 3.4）。完成 / 跳过注销监听。
- **点击的唯一例外**（设计案 3.4）：唯一命中层按 `#btn-help` 豁免洞 rect 判定 —— 命中→只写 `skipped` ＋ 收尾并 `preventDefault()/stopPropagation()`，不派发到 `#btn-help`、不下传游戏；矩形外→吞掉 no-op；**禁止「点遮罩任意处即跳过」**。视觉侧不定义其行为，只保证该区域与「?」可见 / 点击可达。
- 视觉侧**不在气泡内渲染任何快捷键清单**（设计案 2.1）。
- `.guide-scrim` / `.guide-mask` / `.guide-hole` / 洞 SVG 设 `aria-hidden="true"`，不进读屏树。

**焦点可见**：统一 `outline:2px solid var(--amber-lt); outline-offset:2px`（洞 `2px dashed`，offset 3px）；`--amber-lt #ffc987` 对暗底 ≥12:1，满足非文本 ≥3:1。**禁止对可聚焦控件用 `outline:none`**；不依赖 hover 传达聚焦；`button:disabled`（L25）不进 Tab 序列。

**对比度（保守值）**：按 `--panel:rgba(23,20,32,.82)` 合成到 `--bg:#0a0910` ≈ `#14121d` 计算；实际气泡叠在被遮罩压暗的界面上底色更暗、对比度更高，故为保守下限。

| 前景 | 用途 | 对比度 | 判定 |
| --- | --- | --- | --- |
| `--ink #efe6d6` | 气泡正文 | ≈15.2:1 | AAA，正文主色 |
| `--label #c4ced8` | 补充注释 | ≈11.9:1 | AAA |
| `--amber-lt #ffc987` | 标题 / 焦点环 / 当前点 | ≈12.5:1 | AAA |
| `--amber #e8a45c` | 高亮描边 / 已完成点 | ≈8.9:1 | AAA |

- 非文本对比：高亮框描边、气泡边框、焦点环、进度点描边对暗底均 ≥3:1。
- 引导层不得仅靠颜色区分状态；读屏用户通过 `aria-current="step"` +「第 N / 6 步」+ `aria-live` 获得等价信息。
