## 二、创建 Static 创空间

1. 登录国内站 `https://modelscope.cn`（国内站与国际站账号、令牌、内容不互通）。
2. 进入 `https://modelscope.cn/studios` → **创建创空间**。
3. 填写基础信息：

| 字段 | 建议值 |
| --- | --- |
| 空间名称 | `sandeng-wuxiang`（小写字母 / 数字 / 连字符） |
| 显示名称 | 三更灯 · 无相客栈 |
| 简介 | 一夜三客，一人为「无相」。AI NPC 带记忆与脾气，灯只够点六回。 |
| 可见性 | 先选**私有**验收，确认无误后转**公开** |
| License | MIT（仓库已附 LICENSE） |

4. 在部署设置里把 **SDK 类型选为 `Static`**（不是 Gradio / Streamlit / Docker）。
   新版创空间在表单里直接选，无需手写 README YAML 头；本仓库 README 里保留的 YAML 头是兼容旧版的兜底，不冲突。
5. **算力规格选「免费 CPU（2vCPU/16GB）」**。**不要选阿里云 PAI-EAS 付费 GPU**——公开创空间只要有访问就会"保持/触发上线"并**按时持续计费**；本作纯前端、零 GPU 依赖，免费 CPU 足够。绑阿里云 + 实名本身不收费，收费只发生在你主动选付费规格时。

## 三、上传文件

### 方式 A：Git 上传（推荐，文件多、便于迭代）

在创空间「文件 / Files」页选择「通过 Git 上传」，复制平台给出的克隆地址，然后：

```bash
# 在一个空目录里
git clone https://modelscope.cn/studios/<你的账号>/sandeng-wuxiang.git
cd sandeng-wuxiang

# 把本仓库的运行时文件复制进来（注意：不要多包一层目录）
cp -r /path/to/AI造游戏/index.html /path/to/AI造游戏/assets /path/to/AI造游戏/js .
cp /path/to/AI造游戏/README.md /path/to/AI造游戏/LICENSE .

git add -A
git commit -m "feat: 三更灯 · 无相客栈 v1.0.0 (AI NPC / AI 导演 / 影子掌柜 Agent)"
git push origin master
```

> 魔搭创空间仓库分支名以页面显示为准（常见为 `master`）。
> 若 push 需凭据，使用魔搭账号的 **Git 访问令牌**，不要用登录密码。

**必须上传的最小文件集：**

```
index.html
README.md
assets/style.css
js/core.js
js/difficulty.js
js/director.js
js/npc.js
js/game.js
js/agent.js
js/ui.js
js/main.js
js/guide.js
js/llm.js
LICENSE
```

> v1.1.0 起含 `js/guide.js`（新用户操作指引），部署时必须一并上传，否则线上版无引导层。
> v1.2.0 起含 `js/difficulty.js`（四档难度配置定义），**必须上传在 `director.js` 之前的位置由 `index.html` 引入**；
> 漏传会让 `SD.Difficulty` 不存在 → 自动回落原有三夜曲线（游戏能玩、但选档无效且没有四档控件文案）。
> 通过 `cp -r .../js .` 整目录复制可自然包含；若逐项核对，请确认本清单 **14 项**全在。
> `js/llm.js`（L2 云端兜底可选适配器）**默认关闭**，不注入 `window.SANDENG_LLM` 即纯端侧、零网络；必须随包上传，否则 `index.html` 引用 404。

`docs/` 与 `tools/` 属于交付文档与开发期工具，可不上传到创空间（但创作手记需要单独发布到魔搭开发者实践）。

### 方式 B：网页手动上传

在创空间「文件」页逐个新增/上传上述文件；新版支持文件夹粒度上传。
**根目录必须直接出现 `index.html`**，不能套 `dist/`、`build/` 或项目子目录。

### 方式 C：让 AI 助手直接推送

把创空间页面给出的 `git clone https://……git` 地址交给 AI 编程助手，并附一句：
「请帮我推送到魔搭创空间，注意补充创空间部署必须要的文件，参考 https://modelscope.cn/docs/studios/quick-create」。
推送成功后回到创空间手动点「发布 / 部署」。

## 四、部署与验收

1. 保存 Static 部署配置后平台通常自动部署；若未触发，手动点「部署 / 重启 / 重新运行」。
2. 状态变为 **Running** 后打开 `https://modelscope.cn/studios/<账号>/sandeng-wuxiang`。

**验收清单（逐项打勾）**

- [ ] 封面能打开，标题 / 灯笼 / 背景正常，浏览器控制台无 404 / CORS / JS 报错
- [ ] 点「开始守夜」能进对局；三位客人立绘、状态条、物证、话头卡全部渲染
- [ ] 完整玩一局：问话 → 证词入簿 → AI 决策轨迹更新 → 点灯指认 → 结算页
- [ ] 「摊开比对」「工程自检报告」「重新决策对比」弹窗正常
- [ ] `?seed=DEMO&night=2` 能复现同一局；`?autopilot=1` 能看到影子掌柜自动试玩
- [ ] 手机宽度（390px）下操作台吸底、可点、无横向溢出
- [ ] **首次进入自动弹出新用户引导**（六步 G1–G6，可走完 / 可跳过 / 顶栏「?」可重看）；`?guide=1` 可复跑、`?guide=0` 不触发
- [ ] **封面四档难度可选（新手/初级/中级/高级）且默认「初级」**；顶栏显示当前档位；`?difficulty=advanced` 进夜后灯数应为 4；`?difficulty=zzz` 回落初级并提示一次
- [ ] **退出登录 / 无痕窗口**下公开链接仍可访问（先私有验收，再转公开复测）
- [ ] 创空间简介与封面填写完整，便于人气奖点赞

## 五、发布创作手记

1. 打开模板 `https://modelscope.cn/posts/437860`（或 `https://modelscope.cn/learn/437860`），按「AI造游戏｜创作手记模板」六段结构填写。
2. 本仓库 `docs/创作手记.md` 已按模板逐节写好，直接复制正文即可；发布前替换文首两处占位：
   - `**作品试玩链接：**` → 上一步的创空间链接
   - `**演示视频：**` → 演示视频的公开链接
3. 在 **魔搭开发者实践** 发布（入口 `https://modelscope.cn/spotlight`），附 `docs/演示视频.mp4` 与关键截图。
4. 建议带上标签：`AI造游戏`、`创作手记`、`AI NPC`、`魔搭平台`、`Qoder`、`AI应用开发`。

**演示视频上传建议**：魔搭正文通常支持外链视频；可先传到 B 站 / 公众号视频 / 腾讯云 COS 等公开可访问位置，
再把链接写进手记「演示视频」字段。若平台支持直接上传附件，用 `docs/演示视频.mp4`（16 秒 / 1.70 MB / H.264）。

## 七、常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 页面空白 | `index.html` 不在根目录，或 SDK 选成了 Gradio；改回 Static |
| CSS / JS 404 | 相对路径被多包一层目录；确认 `assets/`、`js/` 与 `index.html` 同级 |
| 中文文件名报错 | 运行时文件名全部为 ASCII，已规避；若上传了 `docs/演示视频.mp4` 之类中文名文件，仅作文档不影响页面 |
| iframe 内无法存档 | 创空间 iframe 下 `localStorage` 可能被限制；本作已做内存态兜底，不影响单局试玩 |
| 需要登录才能访问 | 可见性仍是「私有」；改为公开后复测无痕窗口 |
| 想加排行榜 / 服务端状态 | Static 不支持服务端；本作刻意不依赖，需服务端时改选 Gradio 或 Docker |
