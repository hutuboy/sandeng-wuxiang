## 正文

```
【游戏创意】

做剧本杀类游戏时最出戏的一点是：NPC 太听话了。
不管你前面冒犯过他三次，还是刚给他添过茶，他永远回同一句台词。

所以这次我用 AI 做了《三更灯 · 无相客栈》——
一家会记事的客栈。你是掌柜，一夜三客投宿，其中一位是「无相」，
证词和柜上物证对不上。灯只够点六回，天亮前把他认出来。

三位客人不是预设剧本，而是三套真正会做决定的 AI NPC：
· 五维量化状态：信任 / 好感 / 张力 / 疑心 / 定力
· 持久记忆：你问过什么、问了几遍、用什么语气，全都记着
· 规则校验：信任 < 35 死活不交关键物件；张力爆表会直接起身离店，
  这一走就真的关掉一条证据路径；第三夜疑心太高，无相会趁夜遁走
· 措辞按人格 + 状态 + 记忆实时组合，会怼你一句「这题你方才问过一回了」

【核心玩法】

选客人 → 选语气（温问 / 逼问 / 示物）→ 点一张话头
（来路 / 时辰 / 同行 / 行囊 / 信物）→ 读证词 → 和物证交叉比对 → 点灯指认。

每问一句消耗一盏灯，灯尽自动结算。
温问养信任，可能换来「交心透底」的额外证词；
逼问容易拿到直答，但把人逼急了会离店；
示物能压住伪饰，代价是疑心飙升。
三夜难度递增，五种结局，三夜通关还有「守夜人」评级。

最得意的一块是右侧「AI 决策轨迹」面板：
每一轮都把特征向量、九个动作的效用打分、规则掩码（哪些动作被锁、为什么）、
实际选中动作、状态回写和记忆条目全部实时摊开。
不是「我接了个大模型」的黑箱，是能被逐条验证的 NPC 脑子。

【计划使用的 AI 工具】

· AI 编程助手（WorkBuddy Agent）：需求拆解、架构、编码、测试脚本、文档全流程协作
· 端侧自研 AI 决策引擎：量化状态 × 人格权重 → 效用打分 → softmax 采样 → 规则层校验 → 状态回写
· AI 导演：带约束求解的程序化案件生成，保证「唯一矛盾 + 行动点够 + 理想玩家可解」
· 影子掌柜（自动试玩 Agent）：只通过结构化状态/动作接口玩游戏，输出含种子与完整动作序列的轨迹
· 验证工具：Node 多种子不变量自检、Edge 真实浏览器冒烟测试、CDP 真实录屏
· 部署：魔搭创空间 Static 托管

没用外部模型权重，也没放任何密钥在前端——
推理全在浏览器本地完成，断网也能玩，同一 seed 结果逐位可复现。

【预期呈现形式】

· 纯静态网页游戏，点开即玩，桌面 / 手机都适配
· 暗色国风灯笼美术：立绘、夜景、纹理、音效全部代码生成，零外部素材
· 完整三夜流程：开始 → 教学 → 选个难度（新手/初级/中级/高级四档，再叠上三夜递增）→ 结算 → 通关评级，支持存档续玩
· 附 16 秒真实浏览器录屏演示、7 张关键截图、200 组种子自检报告
· 代码 MIT 开源，结构化接口 window.SANDENG_API 开放给二次开发

从「我想玩」到「我来做」，这次真的自己造了一盏灯 🏮
```
