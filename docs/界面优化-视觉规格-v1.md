## 一、风格定义

### 1.1 同源约束（本次改动的唯一色板与材质口径）

- **色板唯一来源**：`assets/style.css` L6–16 `:root`。施工**只引用既有变量，禁止写入新的字面量色值**，避免产生第二套色板。
  标签 `--label:#c4ced8` / `--muted:#9aa7b5`；强调 `--amber:#e8a45c` / `--amber-lt:#ffc987`；危险 `--crimson:#d8534f`（`.btn-danger` 系）；正文 `--ink:#efe6d6`；装饰 `--dim:#6f7482`。
  **任务单中的 `#f0b429` / `#b23a2e` 与现行 `--amber` / `--crimson` 数值不一致，一律视为语义描述，不落地为新 token、不替换既有值。**
- **硬约束：不得出现 `#ccc`**（含 `#cccccc` 等近似灰）；`--dim` 对比度约 4:1，**禁止承载关键信息 / 正文 / 按钮标签**，只用于水印、序号、纯装饰。
- **不改暗色国风主色系**：`--bg/--bg-2/--bg-3/--panel/--panel-2/--line/--line-2` 语义与数值不变；本次只调尺寸、间距、字重、描边权重、区块顺序与折叠状态。
- **圆角 / 材质**：沿用 3px（`.btn`）/ 4px（`.panel`）/ 5px（`.modal`、`.result-wrap`）；半透明暗底 + 1px 琥珀描边 + 极轻琥珀外辉光，与 `.guest-card.selected`（L181）、`.lamp.on`（L131）同源。不引入玻璃拟态高光、大圆角、投影卡片。
- **字体**：只用 `var(--serif)` / `var(--sans)` / `ui-monospace,Menlo,Consolas,monospace`（对齐 `.tb-lamp-label` L134）。**不引入字体文件、不新增第三方字体 / CDN / 图标库**；图标沿用现有字符 `⌂ ♪ AI ? ◈ ✦` 与 CSS 伪元素。
- **零外部资源**：全部改动落到 CSS 变量、选择器、圆角、描边、间距、尺寸比例与折叠状态指令；`assets/` 不新增文件，不产生任何新的图片 / 字体 / 音频 / 网络请求。
- **可读性**：正文 `--ink` 对面板底 ≥15:1；次要文字最低 `--muted`（≥7.6:1）。
- **颜色不得成为唯一信息载体**：话题卡「已问过」、指认按钮「灯已尽」、进度「当前档」等状态必须同时具备**文本 / 描边 / 尺寸 / 填充**中至少一种非颜色差异（详见一.3）。

### 1.2 三级分区定义（贯穿四屏）

| 级别 | 定义 | 视觉权重 | 默认可见性 | 滚动行为 |
| --- | --- | --- | --- | --- |
| **P1 主操作区** | 每屏唯一，承载「这一步必须做的动作」 | 最高：最大字号、最强对比、唯一主按钮填充 | 常驻，不得被滚动推出首屏 | 移动端吸底固定 |
| **P2 信息区** | 决策所需的状态与证据（余灯 / 物证 / 证词 / 客人 / 对话 / 得分 / 真相） | 中：`--ink` 正文 + `--label` 标签 | 默认可见，可折叠摘要但不可整体删除 | 区域内部滚动、限高 |
| **P3 辅助区** | 可延后阅读的说明、工程信息、次要开关与分享 | 最低：`--muted` / `--dim`、最小字号、弱描边 | 默认折叠 / 图标化 / 移入统一菜单 | 不占常驻版面 |

> 分区是**文档标注**，不落成 `class="P1"` 之类类名，避免污染既有样式表；实际落地用 `is-primary` / `is-collapsed` 等状态类（见一.5）。

### 1.4 层级阶梯 token（新增纯尺寸变量，不新增色值）

在 `:root`（L16 之后）追加，供四屏共用，避免逐屏写魔法数字：

```css
--sp-1:8px; --sp-2:12px; --sp-3:20px; --sp-4:32px;  /* 间距节奏：8 / 12 / 20 / 32 */
--tap:44px;                                          /* 移动端最小命中区 */
--fs-micro:11px; --fs-label:12px; --fs-body:13px;
--fs-lead:15px;  --fs-title:18px; --fs-num:20px;     /* 顶栏核心数字 */
```

**合批建议**：所有按钮共用 `.btn` 基类的一套 `:hover/:active/:disabled/:focus-visible` 规则，不逐按钮复制；折叠区共用一个 `.is-collapsed` 状态类；P1 强调统一用 `.is-primary` 修饰，新增规则 ≤ 12 条。

### 1.5 命名与交付规范

- 新增容器类名：`ui-` 前缀（如 `.ui-menu`、`.ui-detail`、`.ui-summary`），**不复用 `.panel`**（其 `overflow:hidden` L74 会裁切展开内容）。
- 状态类名一律 `is-` 前缀（`is-on` / `is-collapsed` / `is-primary`），与既有 `.tier-opt.is-on`、`.icon-btn.on` 同构；`hidden` / `force-show` 保持现状（L147 / L330）。
- **不新增、不重命名、不删除任何 `id`**；`data-action` / `data-modal` / `data-topic` / `data-tier` 属性值一律保持不变（事件委托依赖，见六）。
- 交付物仅本规格文件；施工由主程序在既有 14 文件内完成，`docs/` 与 `tools/` 不进部署包。
- 施工后须复跑 `node tools/guide-smoke.cjs`（60/60）、`node tools/browser-smoke.cjs`（390×844）、`node tools/selftest.cjs --seeds 200 --demo`（6/6）；三套门禁见 `docs/交付清单.md` L92–96。
